Mint 21.15.5 — Updater Race Fix

Problem:
v21.15.4 was published before latest.yml finished uploading. A running Mint client
checked the release during that short window and received a 404.

Fix:
- create the GitHub release as a draft
- upload installer, blockmap and latest.yml
- verify latest.yml + installer are present
- only then publish the release

No UI or backend behavior changes.
