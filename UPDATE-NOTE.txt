Mint 21.13.0 — True Structural Rebuild

This release no longer uses a post-render Mint overlay.

During npm install, scripts/apply-21.13-ui.cjs patches src/app.js directly:
- replaces the native top navigation
- rebuilds Home markup
- rebuilds AI Studio's final markup into a 2-column editing workbench
- rebuilds Library markup into a source sidebar + media grid
- rebuilds Projects into media-first cards
- rebuilds Results using real saved campaign/post data only
- rebuilds Campaign Studio into a campaign sidebar + selected workspace

The patch preserves the existing state, APIs, IDs and data-* hooks used by bind().
No backend endpoints, AI engine, Smart Import, Canto, updater logic, or secrets are changed.
