Mint 21.15.6 — Campaign Page Fix

Fixes the broken Campaign Studio card introduced by 21.15.2.

Cause:
The previous UI enhancer searched every descendant element and could select a large
ancestor whose textContent contained the entire Campaign Studio page. That full page
text was then inserted into Rate / summary fields.

Fix:
- removes global text scraping from Campaign Studio
- reads each campaign only from its native structured campaign card
- analytics popup reads only the selected campaign detail
- preserves real campaign values and avoids concatenated page text
- keeps Results and AI Studio 21.15.2 enhancements
