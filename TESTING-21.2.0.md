# ClipBoost 21.2.0 — Quick test

You can use an existing project. No new upload is required if the original media is still available.

1. Open an existing long video project.
2. Click **Generate variations** once. This reuses the cached transcript and upgrades it to the Quality Engine format.
3. Compare the generated candidates:
   - the beginning should be a complete phrase/hook;
   - the ending should not cut a sentence;
   - duplicate/near-duplicate clips should be reduced;
   - each card now shows Hook / Story / Retention / Clean scores.
4. In **Quality Engine**, test:
   - Speech cleanup → `Clean captions`;
   - Auto zoom → `Natural`.
5. Generate a preview and check punctuation, repeated words and zoom placement.
6. Change Speech cleanup to `Clean speech + captions` only if you want detected stutters/fillers removed from the actual audio as well.
7. Test Caption color with White, Yellow, Red, Green, Blue, Purple, Orange and Black.
8. Export one clip and confirm preview/export stay visually consistent.

Recommended default:
- Speech cleanup: Clean captions
- Auto zoom: Natural
- Dynamic zoom: ON
- Caption color: White
- Smart 9:16 reframing: ON
- Speaker tracking: ON
